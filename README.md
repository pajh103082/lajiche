# 垃圾車來了

給長輩用的垃圾車、資源回收車追蹤和提醒。字大、按鈕大，車子快到時像鬧鐘一樣響。

- **網頁版**（iPhone、Android 都能用）：https://pajh103082.github.io/lajiche/
  - iPhone：用 Safari 打開 →「分享」→「加入主畫面」
  - 網頁版要開著畫面才會響
- **Android App**：`android/` 資料夾（鎖螢幕也會響）

## 支持
覺得好用的話，可以到 [Ko-fi](https://ko-fi.com/sagiriben) 請作者喝杯咖啡。

## 功能
- 輸入地址找附近的垃圾車站，選好後顯示車子還有幾站、大約幾分鐘到
- 垃圾車和資源回收車用不同顏色、不同圖示
- 車子快到時響鈴、震動、語音提醒；可以在地圖上放「提醒點」
- 地圖顯示實際道路的路線、行車方向、往下一站的路線、路線總覽
- 回收車依清潔隊公告的班表和行車紀錄判斷，沒有回收車的日子會顯示

## 資料來源
車子位置和路線來自地方清潔隊使用的垃圾車資料平台（非官方公開 API，可能隨時變動）；地圖是內政部國土測繪中心的臺灣通用電子地圖；補道路用 OSRM。僅供個人使用。
